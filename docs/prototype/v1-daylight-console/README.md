# Prototype screenshots: Study Station

Screenshots of the clickable prototype in [`frontend/prototype/v1-daylight-console/`](../../../frontend/prototype/v1-daylight-console/README.md).
It follows design D from `docs/Wireframe/`, but with **square corners**. All numbers are sample data.

Captured with headless Microsoft Edge: desktop at 1440 px, tablet at 1024 px and
phone at 390 px (2× pixel density).

|---|---|
| `01-sign-in-desktop.png` | Sign in, with the box status list |
| `02-register-desktop.png` | Create account |
| `03-workspace-desktop.png` | Workspace: Climate, Light, Session, Timer, LCD and Session log windows, with the icon dock on the right |
| `04-history-desktop.png` | History: 30-day totals, heatmap, 24 h temperature and humidity, model box, session table |
| `05-settings-desktop.png` | Settings: account, Pomodoro lengths, notifications, device and RFID cards |
