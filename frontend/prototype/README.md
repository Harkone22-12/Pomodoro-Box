# UI prototypes

Static, clickable prototypes of the web app (HTML/CSS/JS, sample data, no build step).
They are not the real app in `frontend/src`. Screenshots are in [`docs/prototype/`](../../docs/prototype/README.md).

| Folder | Design | Language | Notes |
|---|---|---|---|
| [`v1-daylight-console/`](v1-daylight-console/README.md) | Design D from the proposal, with square corners | English | Floating windows, amber, Space Grotesk |
| [`v2-teal-desk/`](v2-teal-desk/README.md) | New design | Vietnamese | Teal sidebar, flat tiles, Nunito, square corners |

Open `index.html` inside either folder in a browser.
